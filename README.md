# ASEIS

Automated Student Enrollment Information System built with Laravel.

## Features
- Student registration
- Subject management
- Enrollment system
- Reports
- Role-based access (Admin / Student)

## Setup
```bash
composer install
php artisan migrate
php artisan serves
